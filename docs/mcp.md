# Today MCP server

Today’s MCP server lets an AI assistant view and manage your todos. Connect the assistant to:

`https://today.harrismccullers.com/mcp`

## Sign-in

Connecting opens Today in your browser. Sign in with your passkey, review the requested access, and choose whether to allow it. You do not need to create or copy an API token, and the assistant can access only your todos.

## Tools

- **List todos:** View your todos, optionally filtered by date or status.
- **Create a todo:** Add a todo on a chosen date.
- **Set todo status:** Mark a todo as to do, postponed, or done.
- **Delete a todo:** Remove a todo from your list.
