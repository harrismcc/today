# UI design

- Remove cruft. Every visible element should help the user understand the current state, make a decision, or take the next action.
- Prefer short, direct copy. Do not repeat information across headings, labels, helper text, and footnotes.
- Avoid decorative icons, badges, nested containers, and visual effects unless they communicate meaning the interface otherwise lacks.
- Preserve essential context, consequences, actions, and error feedback.
